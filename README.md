📌 Описание

В рамках рефакторинга был переработан крипто-анализатор с процедурного подхода на модульную архитектуру с использованием принципов ООП и SOLID.

Система разделена на слои:

CLI → Provider → Portfolio → Formatter
🧠 SOLID принципы в проекте:

S — Single Responsibility Principle (SRP):

Каждый класс отвечает только за одну задачу: CryptoAsset → хранение данных одной криптовалюты CryptoPortfolio → анализ списка криптовалют Provider → получение данных из API Formatter → вывод данных

O — Open/Closed Principle (OCP):

Система открыта для расширения, но закрыта для изменения: можно добавить новый API провайдер (например Binance) без изменения main.py можно добавить новый формат вывода (HTML, XML) без изменения существующего кода

Реализовано через Factory: ProviderFactory FormatterFactory

L — Liskov Substitution Principle (LSP)

Все провайдеры и форматтеры взаимозаменяемы: любой Provider можно заменить другим без изменения логики любой Formatter можно подставить вместо другого

🟡 I — Interface Segregation Principle (ISP)

Форматтеры и провайдеры имеют минимальные интерфейсы: format() — только вывод get_assets() — только получение данных Классы не перегружены лишними методами

🔴 D — Dependency Inversion Principle (DIP)

main.py не зависит от конкретных реализаций: используется Factory зависимости создаются вне бизнес-логики зависимости передаются через абстракции
🧱 Архитектура CLI (Typer) ↓ Provider (API слой) ↓ Portfolio (бизнес-логика) ↓ Formatter (вывод)
🚀 Возможности системы выбор источника данных (coingecko, coinmarketcap) выбор формата вывода (console, json, csv) анализ топ роста и падения криптовалют легко расширяется без изменения основной логики
